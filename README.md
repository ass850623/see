# 霧海之聲

目標為可於 Steam 發行的 Windows 桌面遊戲。已建立離線桌面包裝與打包流程，目前包含第一章、第二章 64 場、第三章 181 場、第四章 117 場可玩流程初版及第五章 137 場原型。第四章章末可明確開始「黨內的門」第 10 日開場與黨內追問，再接續黨內條件、辦公室分工、記者說明與一般通行待問；可接續窗口回覆與來源核對；可接續結果說明與後續補問；可接續補問回覆與說明反應；可接續黨內追問與值班交接；可接續履行準備與待收追蹤；可接續追蹤回報與後續安排；可接續安排執行與回報追問；可接續候選問題與黨內回應；可接續候選追問回覆與分工核對；可接續新回報與責任追蹤；可接續新回報反應與待收續追；可接續待收整理與黨內交班；交班回應與後續分工尚未開放，全作 70 小時目標仍在製作中。詳見 [Steam 發行與桌面開發](docs/steam-release.md)。

```sh
npm ci
npm run desktop
npm run build:win
```

繁體中文、架空政治題材的視覺小說 RPG 原型。玩家扮演主張本土自主的群島議員，目前包含第一章可玩流程、第二章及第三章流程初版、第四章窗口與回訪原型，以及保留的五場事件概念序章。含程式繪製角色立繪、響應式介面與瀏覽器自動存檔。

開發需要 Node.js 22.12 或更新版本。桌面發行使用 Electron 與 electron-builder；玩家執行打包版不需要 Node.js。

```sh
npm start
npm test
```

伺服器預設使用 3000 埠，可透過 PORT 調整。101 項測試涵蓋調查段 9,216 條路線、四種證據組合下的 9,072 條含回訪的聽證續接路線、原序章 243 條路線、證據授權、澄清、承諾與存檔。第一章支援任務簿、證據簿、人物關係、對話紀錄、三時段調查與三欄手動存檔、承諾簿、章節進度與分頁續讀；立繪為示意圖，後續可加入正式美術、音效、任務與更長的分支劇情。
