# 霧海之聲

目標為可於 Steam 發行的 Windows 桌面遊戲。已建立離線桌面包裝與打包流程，目前為第一章加第二章開場、調查與回訪原型的開發版；不是完整 70 小時作品。詳見 [Steam 發行與桌面開發](docs/steam-release.md)。

```sh
npm ci
npm run desktop
npm run build:win
```

繁體中文、架空政治題材的視覺小說 RPG 原型。玩家扮演主張本土自主的群島議員，目前包含第一章可玩流程、第二章隔日承諾追蹤開場原型，以及保留的五場事件概念序章。含程式繪製角色立繪、響應式介面與瀏覽器自動存檔。

開發需要 Node.js 22.12 或更新版本。桌面發行使用 Electron 與 electron-builder；玩家執行打包版不需要 Node.js。

```sh
npm start
npm test
```

伺服器預設使用 3000 埠，可透過 PORT 調整。82 項測試涵蓋調查段 9,216 條路線、四種證據組合下的 9,072 條含回訪的聽證續接路線、原序章 243 條路線、證據授權、澄清、承諾與存檔。第一章支援任務簿、證據簿、人物關係、對話紀錄、三時段調查與三欄手動存檔、承諾簿、章節進度與分頁續讀；立繪為示意圖，後續可加入正式美術、音效、任務與更長的分支劇情。
