# 霧海之聲

繁體中文、架空政治題材的視覺小說 RPG 原型。玩家扮演主張本土自主的群島議員，目前包含第一章可玩流程，以及保留的五場事件概念序章。含程式繪製角色立繪、響應式介面與瀏覽器自動存檔。

需要 Node.js 18 或更新版本，無第三方套件。

```sh
npm start
npm test
```

伺服器預設使用 3000 埠，可透過 PORT 調整。30 項測試涵蓋調查段 9,216 條路線、四種證據組合下的 9,072 條含回訪的聽證續接路線、原序章 243 條路線、證據授權、澄清、承諾與存檔。第一章支援任務簿、證據簿、人物關係、對話紀錄、三時段調查與三欄手動存檔、承諾簿、章節進度與分頁續讀；立繪為示意圖，後續可加入正式美術、音效、任務與更長的分支劇情。

## 長篇製作文件

- [遊戲企劃](docs/game-design.md)：世界、角色、系統與約 70 小時內容目標。
- [第一章任務大綱](docs/chapter-01.md)：證據、調查行程、分支、聽證與驗收。
- [製作路線](docs/production-roadmap.md)：里程碑、現況與下一個工作包。

這些是規劃文件；目前可玩版本是第一章可玩流程與概念序章，尚未達到完整第一章或 70 小時的內容量。

正式第一章存檔使用 mist-chapter-v1- 前綴，概念序章沿用 mist-rpg；開始新第一章只覆寫正式自動存檔，手動存檔與序章存檔仍保留。可從舊試玩終點繼續黨團協商、外交與三輪聽證，章末有四種案件結果和承諾清單。事故正式調查尚未結案，第二章尚未製作；本章尚未達到 90–120 分鐘的目標內容量。

本次新增 22 頁角色與場景敘事（約 1,990 字元），白天辦公室與聽證室背景已接入。閱讀頁碼會自動保存，既有存檔缺頁碼時從該場第一頁續接。承諾簿由已保存的決策推導，故事第 8 日期限不代表現實日期，尚未有第二章可履行承諾。素材來源見 [美術紀錄](assets/ART-CREDITS.md)。

新增三位配角立繪（各一種表情）與港口、工會背景。證據簿可閱讀原始時間與文件限制；證據整理場景可進行可重試的時間線判讀。判讀不改變公開授權、不消耗行程、不重複增加數值，結果隨自動及手動存檔保留。敘事目前共 88 頁、約 7,793 字元（另有九頁現場走訪、約 734 字元），不代表完整第一章的全部稿量或實測時長。

記者支線新增十頁敘事與兩組深入採訪抉擇，共九種組合：消息來源保護與公開更正。要求有利報導會暫停具名專訪，只保留書面回應；更正期限進入承諾簿，聽證與夜談會回應訪談決策。深入採訪不另耗行程，同一問題只能作答一次。

維護調查加入合約、受理與評估文件判讀；技師訪談加入九種作證／支援組合。個人作證可以拒絕，公開文件仍可核對；證人諮詢與申訴窗口承諾會保存，聽證與夜談會回應。缺評估附件只能要求調閱，不能直接推論貪污。

第一章港口走訪新增值班員、店主與船員三條訪談（八種回答組合），結果記入現場札記並影響救助資格、公告安排與聽證回應。現場口述不等同核實證據。新增本機前景遊玩時間記錄，離開遊戲或背景分頁不計入，沒有外部分析上傳。此計時是近似實測工具，不表示章節已達 90–120 分鐘。

幕僚工作板加入時間／授權核對、救助窗口、草案審查三項工作：兩人每人一項，共六種不同分配。確認前可重排，確認後於聽證準備階段交付兩份稿件，未安排工作保留待辦。成果審閱可修正誤解，不改變公開授權或政策完成狀態。新增十二頁主線敘事與六段工作說明；第一章仍未達 90–120 分鐘目標。

聽證後新增工會回訪、媒體補充採訪與夜間幕僚會議：六頁敘事、三組抉擇，共八種後續組合。人物依原聽證結果回應，修復或堅持會影響關係、信任與待履行承諾，但不改寫原始聽證紀錄。舊章末存檔可選「體驗新增聽證後回訪」接續，完成後不能重複取得數值。

回訪交鋒再擴寫十頁：輪班生計、會員署名程序、完整問答與摘要、更正的代價、夜間待辦分工。工會回覆選擇會接入媒體追問，媒體選擇會接入幕僚回應；有利短片造成的專訪暫停也反映於人物關係簿。

許知言新增獨立透明立繪（深藍外套、眼鏡、錄音筆），接入記者訪談、聽證主持與後續採訪。夜談與夜間幕僚會議使用同一間辦公室的雨夜背景。共十張生成素材、四位角色各一種表情；其他角色及部分場所仍是原型美術。

第一章試玩工具：`npm run playtest` 檢查三條代表路線，`npm run playtest:report` 重建[路線報告](docs/chapter-01-route-report.md)。真人步驟见[試玩手册](docs/chapter-01-playtest.md)，另附[空白紀錄 CSV](docs/chapter-01-playtest-records.csv)。尚無真人時長樣本，報告頁數不可當成已达 90–120 分鐘的證明。

新增「試玩紀錄」工具：查看六階段近似前景時間，並手動下載本機 JSON（時間、選擇與待辦），不會上傳。舊存檔已累計時間列為未分類，新計時才分段；離席但分頁仍顯示時仍會計入，真人試玩須自行記錄休息。

技師室與聽證後採訪區已加入專用背景，搭配許安禾及許知言立繪；白天記者訪談仍在港邊咖啡店，不使用電視採訪區背景。素材總數為十二張，咖啡店、外交與走廊仍有原型背景。
