# 霧海之聲

繁體中文、架空政治題材的視覺小說 RPG 原型。玩家扮演主張本土自主的群島議員，目前包含第一章可玩流程，以及保留的五場事件概念序章。含程式繪製角色立繪、響應式介面與瀏覽器自動存檔。

需要 Node.js 18 或更新版本，無第三方套件。

```sh
npm start
npm test
```

伺服器預設使用 3000 埠，可透過 PORT 調整。43 項測試涵蓋調查段 9,216 條路線、四種證據組合下的 9,072 條含回訪的聽證續接路線、原序章 243 條路線、證據授權、澄清、承諾與存檔。第一章支援任務簿、證據簿、人物關係、對話紀錄、三時段調查與三欄手動存檔、承諾簿、章節進度與分頁續讀；立繪為示意圖，後續可加入正式美術、音效、任務與更長的分支劇情。

## 長篇製作文件

這些是規劃文件；目前可玩版本是第一章可玩流程與概念序章，尚未達到完整第一章或 70 小時的內容量。

正式第一章存檔使用 mist-chapter-v1- 前綴，概念序章沿用 mist-rpg；開始新第一章只覆寫正式自動存檔，手動存檔與序章存檔仍保留。可從舊試玩終點繼續黨團協商、外交與三輪聽證，章末有四種案件結果和承諾清單。事故正式調查尚未結案，第二章尚未製作；本章尚未達到 90–120 分鐘的目標內容量。

本次新增 22 頁角色與場景敘事（約 1,990 字元），白天辦公室與聽證室背景已接入。閱讀頁碼會自動保存，既有存檔缺頁碼時從該場第一頁續接。承諾簿由已保存的決策推導，故事第 8 日期限不代表現實日期，尚未有第二章可履行承諾。素材來源見 [美術紀錄](assets/ART-CREDITS.md)。

新增三位配角立繪（各一種表情）與港口、工會背景。證據簿可閱讀原始時間與文件限制；證據整理場景可進行可重試的時間線判讀。判讀不改變公開授權、不消耗行程、不重複增加數值，結果隨自動及手動存檔保留。敘事目前共 96 頁、約 8,368 字元（另有九頁現場走訪、約 734 字元），不代表完整第一章的全部稿量或實測時長。

記者支線新增十頁敘事與兩組深入採訪抉擇，共九種組合：消息來源保護與公開更正。要求有利報導會暫停具名專訪，只保留書面回應；更正期限進入承諾簿，聽證與夜談會回應訪談決策。深入採訪不另耗行程，同一問題只能作答一次。

維護調查加入合約、受理與評估文件判讀；技師訪談加入九種作證／支援組合。個人作證可以拒絕，公開文件仍可核對；證人諮詢與申訴窗口承諾會保存，聽證與夜談會回應。缺評估附件只能要求調閱，不能直接推論貪污。

第一章港口走訪新增值班員、店主與船員三條訪談（八種回答組合），結果記入現場札記並影響救助資格、公告安排與聽證回應。現場口述不等同核實證據。新增本機前景遊玩時間記錄，離開遊戲或背景分頁不計入，沒有外部分析上傳。此計時是近似實測工具，不表示章節已達 90–120 分鐘。

幕僚工作板加入時間／授權核對、救助窗口、草案審查三項工作：兩人每人一項，共六種不同分配。確認前可重排，確認後於聽證準備階段交付兩份稿件，未安排工作保留待辦。成果審閱可修正誤解，不改變公開授權或政策完成狀態。新增十二頁主線敘事與六段工作說明；第一章仍未達 90–120 分鐘目標。

聽證後新增工會回訪、媒體補充採訪與夜間幕僚會議：六頁敘事、三組抉擇，共八種後續組合。人物依原聽證結果回應，修復或堅持會影響關係、信任與待履行承諾，但不改寫原始聽證紀錄。舊章末存檔可選「體驗新增聽證後回訪」接續，完成後不能重複取得數值。

回訪交鋒再擴寫十頁：輪班生計、會員署名程序、完整問答與摘要、更正的代價、夜間待辦分工。工會回覆選擇會接入媒體追問，媒體選擇會接入幕僚回應；有利短片造成的專訪暫停也反映於人物關係簿。

許知言新增獨立透明立繪（深藍外套、眼鏡、錄音筆），接入記者訪談、聽證主持與後續採訪。夜談與夜間幕僚會議使用同一間辦公室的雨夜背景。共十張生成素材、四位角色各一種表情；其他角色及部分場所仍是原型美術。

第一章試玩工具：`npm run playtest` 檢查三條代表路線，`npm run playtest:report` 重建[路線報告](docs/chapter-01-route-report.md)。真人步驟见[試玩手册](docs/chapter-01-playtest.md)，另附[空白紀錄 CSV](docs/chapter-01-playtest-records.csv)。尚無真人時長樣本，報告頁數不可當成已达 90–120 分鐘的證明。

新增「試玩紀錄」工具：查看六階段近似前景時間，並手動下載本機 JSON（時間、選擇與待辦），不會上傳。舊存檔已累計時間列為未分類，新計時才分段；離席但分頁仍顯示時仍會計入，真人試玩須自行記錄休息。

技師室與聽證後採訪區已加入專用背景，搭配許安禾及許知言立繪；白天記者訪談仍在港邊咖啡店，不使用電視採訪區背景。素材總數為十二張，咖啡店、外交與走廊仍有原型背景。

咖啡店、代表處視訊室與議會走廊新增獨立背景，分別用於記者訪談、外交協商與聽證準備；黨團會議室仍使用原型背景，周岳與艾琳仍使用示意角色圖。

沈若川、周岳、艾琳新增獨立透明立繪，黨團會議室新增專用背景；用於聽證準備、協商、聽證及章末結算。主要具名角色均有一張立繪，但尚未加入多表情、動畫或語音。港口廣播仍使用示意圖。

聽證新增八頁交鋒與三組可選追問，各題兩種回答、同題僅作答一次，共八種回答組合。追問校正方法、維護驗收與救助保證；缺 E04 不提供維護卷宗追問。回答記入存檔與對話紀錄，後續幕僚會議回應；七日領款保證新增待回覆與更正承諾。追問不新增證據或授權，也不抹除原主線聽證回答。

夜談與夜間幕僚會議加入「夜間補件桌」，依聽證追問留下的問題出現時間方法、維護釐清與救助更正三份稿（九段說明）。錯誤稿可重寫，通過審閱後保存且不能重複作答；章末可查看成果。備妥稿件不等於發布、取得授權或完成公共承諾，原發言與案件結果保留。

工會與記者回訪可在補件桌審閱已備妥稿件，每位審閱者針對每稿一次作答：納入意見，或保留原稿並記錄異議。結果附在稿件與對話紀錄，重開續玩保留；不新增授權、不代表發布或合作背書。夜間會議才備妥的稿件本章不會倒回較早回訪自動取得審閱。

夜間會議可開啟「發布與回覆排程」：已備妥稿件各分為發布前核對與外部回覆，你和予澄各接一項，確認前可重排，確認後鎖定責任。未安排工作保留待辦，章末可查閱；排程不代表已發布、已聯絡或完成承諾。

確認後續責任後，可開啟「討論後續回覆」。予澄依實際工作負責人、未安排數量與工會／記者異議提出不同追問；玩家決定明日說明安排與限制，或暫不對外說明。通知選擇新增待聯絡承諾，回應一次保存，章末可查閱。

章末可閱讀六頁交接，依存檔整理待履行承諾、補件、責任與審閱分歧。新增尚未核對的維護來信伏筆，可保存第二日優先核對來源或追救助窗口的交接意向；不新增核實證據或完成原承諾。第二日可玩流程尚未製作。

`npm run audit:chapter` 檢查所有場景素材路徑與一條完整支線整合路線，結果見[內容驗收快照](docs/chapter-01-content-audit.md)。章末交接面板開啟時現在計入前景時間，關閉後結算停止；新版計時不能補回舊版未計入的交接時間。真人時長仍未驗收。


### 黨團逐條協商
新增管制範圍、七日失效與申訴、贊助利益申報三項各二選一的協商。回答只記錄一次並保存；後續聽證、夜間幕僚與結算追蹤資源取捨及立場落差。協商仍為提案，未完成修法、任命或正式調查。可略過，既有存檔與主線選項保留。自動測試現為 45 項；第一章 90–120 分鐘及全作 70 小時仍待真人試玩與後續章節製作驗收。


### 外交逐項協商
新增援助與共同聲明、跨境資料用途、保密重審與撤回權三項各二選一協商。海西、旭輪與西陸提出不同條件；回答一次並存檔，後續聽證、採訪、幕僚及結算追蹤未決事項。最後救援優先或公開監督立場會改變後續說明。協商不會交付援助、讓協議生效或擴大現有公開授權。八種組合乘三種主線立場通過驗證，全部自動測試現為 47 項；目標時長仍待真人試玩驗收。
