# Steam 桌面發行方向

本專案以 Windows 64 位元桌面遊戲為首個發行平台，Electron 包裝現有視覺小說 RPG。網頁版保留作開發與快速試玩；第一章不是完整 70 小時遊戲，目前只能作內部測試版本。Steam 商店頁尚未建立，也沒有上傳任何 Steam depot。

## 開發與打包

需要 Node.js 22.12 或更新版本。玩家不需要安裝 Node.js、開啟伺服器或保持網路連線。

```sh
npm ci
npm run desktop
npm run build:win
```

Windows 完整發行資料夾為 `dist/win-unpacked`，執行檔為 `VoicesOfTheMist.exe`。必須連同 resources、DLL 與其餘檔案一起配送，不能只上傳 exe。版本目前未簽署、使用 Electron 預設圖示；正式發行需製作專用圖示與版本資訊，再按需要設定程式簽署。跨平台建置 Windows 包不代表 Windows 執行驗收通過。

`npm run build:desktop` 在當前作業系統建立未封裝資料夾。Linux 圖形環境可執行 `npm run test:desktop` 驗證離線資源、隔離的渲染程序及關閉後續玩；無顯示器的測試環境須另外提供 X server。受限雲端環境可加 `--config.electronDownload.cache=/tmp/mist-electron-cache` 指定下載快取，開發 Electron 二進位下載可用 `electron_config_cache=/tmp/mist-electron-cache node node_modules/electron/install.js`。

桌面透過固定 `mist://game/` 來源載入本機資源，不使用 localhost 埠。F11 切換全螢幕，Escape 可退出全螢幕；全螢幕、輸入法與縮放仍需 Windows 實機測試。程式不開放 Node.js 給頁面，阻擋新視窗與外部導覽。

## 存檔

桌面資料固定保存在 Electron appData 下的 `voices-of-the-mist/saves` 資料夾，Windows 通常位於 `%APPDATA%\voices-of-the-mist\saves`。正式故事每個欄位保存為獨立、帶版本的 JSON envelope；內容仍使用既有 schemaVersion 1，先驗證後寫入暫存檔再 rename。上一次有效資料保存為 `.bak`，主檔損壞時讀取有效備份並提示。損壞原檔讀取時不改寫；後續保存前將其另存 `.corrupt-時間戳`。主檔與備份均損壞時提示錯誤，不拿舊瀏覽器資料覆蓋。

首次升級會把同一桌面來源內有效的 localStorage 欄位遷移至空白檔案欄位，原資料保留；已有檔案優先，無效或損壞檔案不自動遷移覆寫。網頁瀏覽器屬另一來源，不會自動匯入。概念序章與試玩回饋目前仍存於 localStorage，正式存檔與遊戲設定使用獨立檔案。手動匯入匯出已加入，Steam Cloud 尚未實作；後續 Cloud 只考慮正式 saves 目錄的有效檔案，不同步整個 Chromium profile。

設定介面可在主畫面或遊玩中開啟，提供三種對話字級、高對比文字底色及桌面全螢幕操作。設定獨立保存，不隨讀檔回退。環境音預設關閉，設定可啟用與調整音量；背景音樂與配音尚未加入。Tab 與 Enter 使用原生按鈕鍵盤操作；全螢幕與中文輸入法仍待 Windows 實機確認。


## Steamworks 銜接

1. 由作品持有人建立 Steamworks 合作伙伴帳戶與遊戲 App，完成平台要求的身分、稅務及付款設定。
2. 取得真實 App ID 與 Windows Depot ID。將 `steam/*.vdf.example` 複製為 `.vdf` 並取代佔位字。範本預設 `Preview 1`，先檢查映射，不會發布分支；設定檔由 scripts 目錄執行時路徑須確認。
3. 透過 Steamworks SDK ContentBuilder／SteamPipe 上傳 `dist/win-unpacked` 的全部內容。Steamworks 的 Windows 啟動選項設定為 `VoicesOfTheMist.exe`。本專案不含帳戶登入或自動發布指令。
4. 在私人測試分支安裝與驗證，確認離線遊玩、存檔升級、Steam 啟動及關閉、Overlay、不同螢幕與系統權限。未測的平台不列為支援平台。
5. 商店素材、遊戲與內容問卷完成後，依 Steamworks 當時的審查與發布流程送審。Steam SDK、成就或 Cloud 並非目前已完成的功能，不在商店宣稱。

官方文件：[SteamPipe](https://partner.steamgames.com/doc/features/steampipe)、[上傳版本](https://partner.steamgames.com/doc/sdk/uploading)、[發行流程](https://partner.steamgames.com/doc/store/releasing)、[Steam Cloud](https://partner.steamgames.com/doc/features/cloud)。依實際帳戶介面確認最新要求。

## 發行前工作包

- 桌面垂直切片：設定介面、字級與音量、鍵盤操作、獨立存檔檔案與備份、專用圖示；先驗收第一章，不以工具數量計算遊玩時長。
- 完整製作：24 章／4 部的劇情、任務、分支承接、角色演出與音效；70 小時為全作目標，需實際內容與真人樣本支持。
- 素材與商店：核對所有圖片、字型、音樂與聲音的發行權利；目前生成美術須按 Steam 內容問卷如實填寫預生成 AI 素材使用情況。製作 capsule、截圖、預告片與準確的內容描述。
- 平台測試：Windows 10/11 支援版本、低配設備、重啟及更新存檔、下載與桌面路徑、鍵盤與中文輸入法；未承諾控制器或 Steam Deck 支援。

本輪驗證：Windows x64 與 Linux 發行資料夾均成功建置；Linux 打包版的離線圖片、渲染隔離、存檔與重開續玩通過。57 項遊戲測試及章節內容整合檢查通過。Windows 實機、Steam 上傳與完整內容均未驗收。


## 玩家搬移與備份管理

遊玩中開啟「存檔／讀檔」，每個有效欄位可匯出 `mist-save-欄位.json`。匯出是版本化遊戲存檔，與試玩回饋／時間紀錄 JSON 不同。

選擇匯入檔案後先檢查場景、選擇次數與累計時間，再選擇手動欄位 1–3；確認覆寫才寫入，當前遊玩狀態不變。之後按該欄位讀取接續。支援本版匯出格式及正式桌面存檔 envelope，拒絕不相容版本、不合法狀態與超過 8 MB 的檔案。匯入不包含設定、概念序章或回饋，也不擴大遊戲證據授權。

桌面每個欄位可預覽上一份有效 `.bak`。恢復手動備份只取代該欄位；恢復自動備份會取代自動欄位及當前遊玩進度，均要求確認。恢復也沿用寫入時的有效備份保護。只有一份輪替有效備份，不是完整歷史版本清單；損壞檔案仍另外保留。瀏覽器版提供匯入匯出，但沒有桌面檔案備份入口。

Linux 桌面與瀏覽器已驗證匯入預覽、取消不寫入、確認指定欄位寫入及備份預覽；桌面重開自動回復備份也通過。Windows 實機仍待驗收。


### 桌面主選單與玩家指引
主選單提供新遊戲、續玩位置、存檔管理、設定、操作說明與素材資訊；桌面另有確認退出。無自動進度時仍可從主選單匯入手動欄位並讀檔，概念序章收在其他試玩。指引說明三時段、可選支線、授權與存檔搬移，明示第一章開發版，不宣稱已達 70 小時。57 項測試、主選單手機與 Linux 桌面驗證通過，Windows 實機仍待測試。下一工作包：第一章桌面試玩包整理與 Windows 驗收紀錄。


### Windows 第一章驗收包
`npm run package:win` 重建 Windows 發行資料夾並產出含啟動說明、14 項實機檢查、空白結果表與 BUILD-INFO 的 ZIP。`npm run package:win:kit` 只整理已有包，會拒絕來源程式或美術已過期的包。每個發行檔案記錄 SHA-256，ZIP 另有 `.sha256` 校驗檔；來源 commit 與是否有未提交修改均寫入版本資訊。驗收表預設未測試，Windows 實機、Steam 與真人時長沒有自動通過。下一工作包：依 Windows 真人結果修正問題；尚無結果時先補齊桌面測試與異常回報工具。


### 本機問題回報
主選單與案件工具新增問題回報：可輸入最多 2000 字重現描述、預覽與下載 JSON。本次啟動保留最近 30 筆錯誤類型及場景，排除原始錯誤文字、檔案路徑與完整存檔；不自動上傳、不跨啟動保存。桌面附版本、來源 commit、未提交修改狀態與載入／渲染程序退出事件。無法啟動整個遊戲或介面失效時，仍須人工填寫驗收表；本工具不是完整當機轉儲。58 項自動測試通過，Windows 實機仍未驗收。下一工作包：第一章桌面鍵盤體驗與可讀性修整。


### 鍵盤與大字級修整
面板重建保留焦點與捲動位置，關閉回到入口；載入另一場景時保留新場景焦點。新增鍵盤可見的跳至對話／主線選擇入口。大字級擴及選項、輸入與表格，焦點框及高對比底色加強。`node scripts/keyboard-smoke.mjs` 在啟動開發伺服器後檢查面板焦點、Tab、最大字級與 390px 窄視窗；可用 MIST_TEST_URL 指定測試網址。58 項測試及瀏覽器、Linux 桌面驗證通過，Windows 實機與輔助閱讀器仍待測試。下一工作包：加入第一章演出與音訊規劃，讓桌面垂直切片更接近完整遊戲。


### 第一章環境音
加入四種即時程式合成環境聲：港口、室內、聽證與夜雨；沒有外部取樣。預設關閉，設定可開啟、調整音量及靜音；主畫面、背景分頁、結算暫停，舊設定沿用顯示選項且新增音效預設關閉。60 項測試、`node scripts/ambience-smoke.mjs` 瀏覽器音訊與 Linux 桌面驗證通過；Windows 音訊實機仍待測試。下一工作包：場景切換與角色出場演出，尊重降低動態效果偏好。

### 第一章場景與角色演出
背景更換時淡入 320ms，角色更換時淡入並輕微上移 240ms；演出不阻擋翻頁與選擇。翻頁沿用圖片節點，工具面板與讀檔不重播。設定新增可保存的演出開關，舊設定預設開啟；系統「減少動態效果」優先停用並取消進行中的動畫。`node scripts/presentation-smoke.mjs` 驗證實際動畫、圖片節點保留、開關保存與系統偏好。角色仍為單張立繪。Windows 實機尚未驗收，70 小時仍是全作目標。下一工作包：第一章流程導引與任務入口整理，改善主線和支線的辨識。

### 第一章流程導引與入口
26 個場景加入目前目標與當前階段；閱讀、主線回應、調查訪談與章末工具分別標示。任務與證據可直接開啟，支線跳轉僅在當場存在支線入口時顯示。調查顯示剩餘時段及每次拜訪成本，離場提示說明未完成內容不會自動補做。導引依讀檔重建，不改變選項、存檔格式或任務結果。60 項既有測試與全章瀏覽器導引驗證通過，Windows 實機仍待驗收。下一工作包：第二章開場與承諾追蹤的可玩原型；70 小時仍為全作目標。

### 第二章隔日追蹤開場原型
第一章結算提供「開始第二章開場（原型）」，五個場景保留昨日聽證、交接意向、證據授權與承諾期限。玩家選一項原承諾，先回覆現況或補核對，再記錄下一輪追蹤；狀態區分待履行、已回覆結果待追蹤、核對中尚未回覆，沒有自動完成任何承諾或正式稿件發布。原 schemaVersion 1 與欄位沿用，chapter 新增 c02，舊存檔可讀；較舊遊戲版本無法讀取 c02 進度。逐頁、自動／手動存檔、搬移與離線續玩均支援。原型暫停點停止前景計時及環境音。63 項自動測試與 `node scripts/chapter-two-smoke.mjs` 檢查分支、授權不變、期限不變、跨章與讀檔；Windows 實機仍待驗收。下一工作包：維護來信來源核對與救助窗口回覆的第二章調查分支。第二章未完成，70 小時尚未達成。

### 第二章維護來信與救助窗口調查
開場暫停點可接續兩條調查，新增調查桌、維護來信、受理窗口、救助詢問、資格說明及調查暫停點六場。兩條均可處理，可自由安排順序；已處理分支不重複，兩條完成後進入結果整理。任務簿分開保存初步核對、原卷待調閱與窗口說明、個案待審，第一章證據授權、原期限與承諾履行情況不變。舊 c02End 存檔可從新入口接續；新進度支援逐頁、搬移與離線重啟。65 項測試涵蓋兩種順序及 32 個分支組合；瀏覽器檢查舊檔續接、途中讀檔與任務結果。Windows 實機仍待驗收，第二章尚未完成。下一工作包：原卷調閱申請與救助卡點的追蹤回訪。

### 第二章原卷申請與救助卡點回訪
調查暫停點提供「接續原卷申請與救助回訪」，新增回訪桌、申請範圍、收件紀錄、工會回訪、文件卡點與回訪暫停六場，第二章原型共 17 場。上輪原卷／比對、轉介／待確認的選擇影響對話。兩條可自行決定順序，完成後不重複；原卷申請區分收件、範圍待釐清、修正待受理與文件未交付，救助區分已知清單、替代文件待確認與個案未審。原授權、案件任務與承諾履行狀態不被自動改寫。舊調查存檔可接續，支持逐頁、搬移及離線重啟。67 項自動測試含 64 種回訪組合，瀏覽器驗證入口、前輪選擇、途中讀檔及任務結果。Windows 實機仍待驗收。下一工作包：文件交付核對與替代文件正式回覆；第二章未完成，70 小時仍為全作目標。

### 第二章文件交付與一般書面回覆
回訪暫停點提供「接續文件交付核對與正式回覆」，新增四場，第二章原型共 21 場。版本申請／修正範圍者收到可公開的附件清單與版本紀錄 E07，初始未核實，選擇比對才更新；完整卷宗仍未釐清者只收到補正通知，可補送範圍或保留需求，不產生 E07。E07 不含非公開原卷、不證明寄件者或竄改，其他證據授權保持原狀。一般書面補件答覆可轉達或保存待釐清，不代表個案核定或撥款。任務簿區分最新結果與前輪申請紀錄，支持舊檔接續、逐頁、搬移及重啟。69 項自動測試包含 64 種交付／回覆組合，瀏覽器驗證兩條文件路徑、核實與中途讀檔。Windows 實機仍待驗收。下一工作包：來源追問與公開補充說明；第二章未完成，70 小時尚未達成。

### 第二章來源追問與公開補充說明
交付暫停點提供「接續來源追問與公開補充說明」，新增四場，第二章原型共 25 場。可追問經手日期／取得方式或暫停；來源僅部分自述，未自動核實身分或取得來信公開同意。E07 版本稿要求核實與公開授權，未核實／缺件者只能準備一般進度說明；草稿引用確認與正式發布分開。審閱後可發布或暫存，僅發布增加本次信任效果。發布文字存為原文快照，工具「補充說明紀錄」只列已發布本段，對話紀錄仍保留草稿與選擇；不自動完成原正式更正或完整聽證附錄。71 項測試涵蓋 16 條合法來源／發布路線、資料授權不變、非法公開範圍拒絕與存檔搬移。瀏覽器驗證核實、未核實與缺件三路及重載紀錄。Windows 實機仍待驗收；第二章未完成。下一工作包：黨團與記者對補充說明的回應及協商分歧。
