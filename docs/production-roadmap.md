## 下一個具體工作包：第一章基礎引擎

1. 建立有穩定 ID 的場景、選項、條件、效果與下一場景格式；文案不混入 DOM 程式。
2. 建立帶 schemaVersion 的遊戲狀態與獨立正式存檔鍵值；保留原 mist-rpg 序章資料。
3. 加入任務簿與證據簿，先接 c01_010–c01_030 的完整試玩稿。
4. 加入三時段調查、一次性訪談與必要線索兜底。
5. 加入對話紀錄、三個手動存檔與自動存檔。
6. 用分支可達性、證據授權、錯過任務、讀檔及章末優先序測試驗收，再寫完整第一章。

第一個交付是具有真正分支與證據系統的 20–30 分鐘試玩段；這是目標，須完成內容與實測才能宣稱達成。

## 估算紀錄

每個工作包記錄劇本字數（單一路線與全部分支分開）、場景數、美術素材數、實際工時、玩家時間中位數、修正次數。第一章結束後，以此推算全篇人力與費用，並重新檢查 70 小時範圍；不使用未知人力下的日曆承諾。
