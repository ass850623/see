霧海之聲｜第一章與第二章開場 Windows 開發試玩版

1. 完整解壓縮此 ZIP，保留 VoicesOfTheMist 資料夾內全部檔案。
2. 在該資料夾雙擊 VoicesOfTheMist.exe；不用安裝 Node.js 或啟動伺服器。
3. 首次試玩選「開始第一章」，依自己的想法遊玩。不要為了時長刻意停留。
4. 操作說明、設定與存檔管理均在主選單。F11 切換全螢幕，Escape 退出；Tab 選按鈕、Enter 確認。
5. 桌面存檔通常位於 %APPDATA%\voices-of-the-mist\saves，更新前可從存檔管理匯出進度。
6. 完成後填 acceptance-record.csv，另在遊戲「試玩指引與回饋」保存並下載 JSON。

此版本包含第一章、第二章開場及兩條調查原型與短篇概念序章；第二章後續未開放，全作 70 小時目標尚未完成。
已加入程式合成環境音，預設關閉，可在設定開啟及調整音量；目前沒有背景音樂或配音。圖片包含預生成 AI 素材。
Windows 包尚未簽署。若系統阻擋啟動，請記錄阻擋訊息；不要關閉系統防護。
測試者請使用匿名代碼，不填真實姓名、Steam 登入或其他不必要個資。

版本與檔案雜湊見 BUILD-INFO.json；此資料只描述打包來源，不代表 Windows 驗收通過。
驗收步驟見 WINDOWS-CHECKLIST.md。請把功能複查與自然初玩分開記錄。

遇到問題：從主選單或案件工具開啟「問題回報」，填寫重現步驟，先檢查預覽後下載 JSON。記錄只涵蓋本次啟動最近 30 筆錯誤，不是當機轉儲；若整個遊戲無法啟動，請在驗收表寫下系統訊息。資料不會自動上傳。

場景與角色切換有短暫淡入，不會阻擋操作。可在設定關閉「場景演出」；系統「減少動態效果」也會停用。請複查開關保存、連續翻頁與讀檔是否穩定。

目前目標顯示於章節頂端，可查看任務、證據或跳至本場支線。調查訪談消耗時段，深入支線不另外扣時段。請確認大字級、讀檔後目標與支線跳轉正確。

第二章入口在第一章結算的「開始第二章開場（原型）」。進入會接續並更新自動存檔；若想保留結算點，可先保存手動欄位。原型可選一項原承諾跟進，回覆不代表履行；請驗證第二章逐頁讀檔及承諾狀態。

第二章開場暫停點可選「接續第二章調查」，先後完成維護來信與救助窗口分支。可在任務簿查看初步結果；原卷調閱及個案結果仍待追蹤。舊開場存檔可以接續。

調查暫停點新增「接續原卷申請與救助回訪」。可選版本或完整卷宗範圍、保存或補送修正，並處理救助文件卡點。任務簿顯示申請收件、範圍或受理待確認與救助答覆待收；文件交付與個案結果尚未開放。

回訪暫停點新增「接續文件交付核對與正式回覆」。限定版本申請可收到 E07 公開清單，選擇比對才核實；完整卷宗範圍未釐清者只有補正通知。一般書面補件回覆不是個案核定。請確認舊檔續接、E07 狀態及結果保存。

交付暫停點新增「接續來源追問與公開補充說明」。核實且可公開的 E07 可支援版本稿，缺件或未核實者改選進度稿。審閱後發布或暫存；「補充說明紀錄」只顯示已發布本段，草稿可在對話紀錄回看。原正式更正與完整聽證紀錄沒有自動完成。

公開回覆暫停點新增「接續黨團與記者回應」。選擇黨團發言協調方式、記者回覆及下輪議程焦點；任務簿顯示待確認意向，未發布草稿不出現在外部角色回應或公開紀錄，原專訪分歧保留。第二章原型共 29 場，尚未完成全章。

回應暫停點新增「接續具體提案與條件取捨」。依上輪焦點逐項談查證與人手條款；共同席有合作與迴避前提，審閱後可簽有限工作約定或保留修訂。任務簿區分草案、簽署與待執行，原期限與資料授權保留。第二章原型共 34 場，完整章節尚未完成。
