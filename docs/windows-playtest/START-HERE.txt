霧海之聲｜第一至第四章原型 Windows 開發試玩版

1. 完整解壓縮此 ZIP，保留 VoicesOfTheMist 資料夾內全部檔案。
2. 在該資料夾雙擊 VoicesOfTheMist.exe；不用安裝 Node.js 或啟動伺服器。
3. 首次試玩選「開始第一章」，依自己的想法遊玩。不要為了時長刻意停留。
4. 操作說明、設定與存檔管理均在主選單。F11 切換全螢幕，Escape 退出；Tab 選按鈕、Enter 確認。
5. 桌面存檔通常位於 %APPDATA%\voices-of-the-mist\saves，更新前可從存檔管理匯出進度。
6. 完成後填 acceptance-record.csv，另在遊戲「試玩指引與回饋」保存並下載 JSON。
