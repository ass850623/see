建議至少涵蓋 Windows 10 與 Windows 11 的受支援設備；本文件不是已測支援宣告。記錄實際 CPU、RAM、顯示卡與系統版本，尚不公布最低配備。

若測試存檔損壞回復，只在另行備份的測試資料上操作，不修改唯一進度；將結果附於 W10。不能用 Linux 回復測試代替 Windows 實機測試。

首次自然初玩另外記錄人工有效遊玩分鐘、休息分鐘與是否完成。未測量留白，不填估算數字；目前沒有真人驗收樣本。Steam 啟動、Overlay 與 Steam Cloud 均不在此離線包內驗收。
